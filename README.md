# Fem Spa Cancún

Landing page de Fem Spa Cancún, con el concepto "Tinta y oro". Es un sitio estático: HTML, CSS y JS sin dependencias ni paso de compilación.

- `index.html`: contenido y SEO local (schema `DaySpa`)
- `styles.css`: paleta, tipografía, texturas de tinta y animaciones
- `main.js`: pestañas de rituales, animación al hacer scroll, vetas doradas y carrusel de reseñas

Para verlo, abre `index.html` en el navegador o publícalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
